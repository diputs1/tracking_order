-- ============================================================
-- ORDER TRACKING SYSTEM — API v3 (LEAN)
-- ============================================================
-- Chỉ giữ API phục vụ nghiệp vụ:
--   GĐ0: Order Management (Cart, Inventory, Pricing, Payment)
--   GĐ1: Order Ingestion
--   GĐ2: State Machine (Status Management)
--   GĐ3: Tracking Logs
--   GĐ4: Async Notifications
--   Bổ trợ: Auth, Products, Addresses, Shipping, Discounts
-- ============================================================


== 1. AUTH =============================================================

Method   Endpoint                              Mô tả
------   --------                              -----
POST     /api/v1/auth/register                 Đăng ký tài khoản (body: full_name, email, password, phone, role[])
POST     /api/v1/auth/login                    Đăng nhập (body: email, password)
POST     /api/v1/auth/logout                   Đăng xuất
POST     /api/v1/auth/forgot-password          Gửi email reset password (body: email)
POST     /api/v1/auth/reset-password           Đặt lại mật khẩu (body: token, new_password)


== 2. USER PROFILE =====================================================

Method   Endpoint                              Mô tả
------   --------                              -----
GET      /api/v1/users/me                      Lấy thông tin profile hiện tại
PUT      /api/v1/users/me                      Cập nhật profile (body: full_name, phone, avatar_url)
PUT      /api/v1/users/me/password             Đổi mật khẩu (body: old_password, new_password)


== 3. ADDRESSES ========================================================

Method   Endpoint                              Mô tả
------   --------                              -----
GET      /api/v1/addresses                     Danh sách địa chỉ của user
POST     /api/v1/addresses                     Thêm địa chỉ mới
PUT      /api/v1/addresses/{addressId}         Sửa địa chỉ
DELETE   /api/v1/addresses/{addressId}         Xóa địa chỉ
PATCH    /api/v1/addresses/{addressId}/default Đặt làm địa chỉ mặc định


== 4. CATEGORIES =======================================================

Method   Endpoint                              Mô tả
------   --------                              -----
GET      /api/v1/categories                    Danh sách danh mục (tree structure, filter: parent_id)
POST     /api/v1/categories                    Thêm danh mục (Admin)
PUT      /api/v1/categories/{categoryId}       Sửa danh mục (Admin)
DELETE   /api/v1/categories/{categoryId}       Xóa danh mục (Admin)


== 5. PRODUCTS (Quản lý sản phẩm — Seller) ============================

Method   Endpoint                              Mô tả
------   --------                              -----
GET      /api/v1/products                      Danh sách sản phẩm (search: sku/tên, filter: category/status/seller, sort, pagination)
GET      /api/v1/products/{productId}          Chi tiết sản phẩm
POST     /api/v1/products                      Thêm sản phẩm mới (Seller/Admin)
PUT      /api/v1/products/{productId}          Sửa sản phẩm (Seller/Admin)
DELETE   /api/v1/products/{productId}          Xóa sản phẩm - soft delete (Seller/Admin)


== 6. INVENTORY ========================================================

Method   Endpoint                              Mô tả
------   --------                              -----
GET      /api/v1/inventory                     Danh sách tồn kho (filter: product, low_stock)
GET      /api/v1/products/{productId}/inventory  Kiểm tra tồn kho real-time cho 1 sản phẩm
PUT      /api/v1/inventory/{inventoryId}       Cập nhật số lượng tồn kho (Seller/Admin)


== 7. CART (Giỏ hàng — Buyer) =========================================

Method   Endpoint                              Mô tả
------   --------                              -----
GET      /api/v1/cart                          Lấy giỏ hàng + trạng thái tồn kho
POST     /api/v1/cart/items                    Thêm sản phẩm vào giỏ (body: product_id, quantity)
PUT      /api/v1/cart/items/{itemId}           Cập nhật số lượng
DELETE   /api/v1/cart/items/{itemId}           Xóa sản phẩm khỏi giỏ
DELETE   /api/v1/cart                          Xóa toàn bộ giỏ hàng


== 8. ORDERS (GĐ0 + GĐ1 + GĐ2) =======================================

Method   Endpoint                              Mô tả
------   --------                              -----
POST     /api/v1/orders                        Đặt hàng — chuyển cart → order (body: address_id, carrier_id, payment_method, discount_code, note)
GET      /api/v1/orders                        Danh sách đơn hàng (Admin/Seller: filter, search, pagination)
GET      /api/v1/orders/my                     Danh sách đơn của buyer (tabs: Tất cả / Đang xử lý / Vận chuyển / Đã giao / Đã hủy)
GET      /api/v1/orders/{orderId}              Chi tiết đơn hàng (items, payment, shipping address, timeline)
PATCH    /api/v1/orders/{orderId}/status       Cập nhật trạng thái — State Machine (body: status, note, reason)
PATCH    /api/v1/orders/{orderId}/cancel       Hủy đơn hàng (body: cancel_reason)


== 9. ORDER TRACKING (GĐ3 — Ghi vết) ==================================

Method   Endpoint                              Mô tả
------   --------                              -----
GET      /api/v1/tracking/{orderId}            Timeline hành trình đơn hàng (danh sách tracking_logs)
POST     /api/v1/tracking/{orderId}            Thêm tracking event (body: location, note, event_type, proof_image_url)


== 10. PAYMENTS (GĐ0 — Thanh toán) ====================================

Method   Endpoint                              Mô tả
------   --------                              -----
GET      /api/v1/payments/{orderId}            Lấy thông tin thanh toán của đơn
POST     /api/v1/payments/{orderId}/pay        Khởi tạo thanh toán online (trả redirect URL cho VNPAY/MOMO/STRIPE)
POST     /api/v1/payments/callback/{provider}  Webhook callback từ payment gateway


== 11. SHIPPER =========================================================

Method   Endpoint                              Mô tả
------   --------                              -----
GET      /api/v1/shipper/tasks                 Danh sách đơn đang giao + metrics (delivered/failed today)
POST     /api/v1/shipper/scan                  Quét mã QR lấy thông tin đơn hàng
PATCH    /api/v1/shipper/orders/{orderId}/status  Cập nhật trạng thái: picked_up / in_transit / delivered / failed
POST     /api/v1/shipper/orders/{orderId}/confirm-delivery  Xác nhận giao hàng (body: proof_image_url hoặc signature)


== 12. SHIPPING CARRIERS (Admin) ======================================
